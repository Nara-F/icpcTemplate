## 10.2 序列、搜索、DP 与数据结构 {#q-index-basic-dp-ds}

| 题意关键词 | 候选模板 | 区分信号 |
|---|---|---|
| 区间和、矩形和、批量区间加 | 前缀和与差分 | 静态查询用前缀；批量修改后统一恢复用差分 |
| “最小可行/最大可行”、单调答案 | 二分答案 | 必须证明判定谓词单调 |
| 有序数组两端、连续区间、窗口 | 双指针与滑动窗口 | 指针只向前；和式窗口常要求非负数 |
| 值域很大但只关心相对次序 | 离散化 | 后续是否仍需原值距离 |
| 逆序对、跨左右两段统计 | 分治与归并计数 | 合并时计算跨区间贡献 |
| 区间最多选若干、按结束时间选 | 贪心与区间调度 | 交换论证；别凭局部直觉 |
| 连通块、枚举路径、递归状态 | DFS | 深度可达 $n$ 时注意栈溢出 |
| 最少步数、分层扩展、等权图 | BFS | 入队即标记；状态空间是否过大 |
| 边权只有 0/1、最短路 | 0-1 BFS | 0 边放队首，1 边放队尾 |
| 排列/组合枚举、满足约束的方案 | 回溯与剪枝 | 恢复现场；估算指数规模 |
| 要输出满足限制的对象而非计算最优值 | [常用构造题思路](#constructive-algorithms) | 先证明可行条件，再核对不变量和小规模样例 |
| $n\approx40$ 的子集枚举 | 折半搜索 | 两半状态能否排序/哈希合并 |
| 每件最多一次、容量限制 | 0-1 背包 | 容量倒序 |
| 每件无限次/有限次数 | 完全/多重背包 | 完全背包容量正序；多重拆分 |
| 每件最多一次、容量限制 | [0-1 背包](#42-0-1) | 组限制需另写组间转移；本章未给分组背包模板 |
| 最长严格/非严格上升子序列 | LIS | 严格用 `lower_bound`，非严格常用 `upper_bound` |
| 两串保序公共序列、编辑操作 | LCS / 编辑距离 | 子序列不要求连续 |
| 合并相邻段、括号/回文区间 | 区间 DP | 按区间长度递增 |
| 树上选点、子树贡献 | 树形 DP | 父子方向；是否要换根得到全点答案 |
| 每个点作根的答案 | 换根 DP | 先子树 DP，再父到子传贡献 |
| $n$ 很小、集合状态 | 状压 DP | 估算状态数与转移枚举 |
| 统计 $[0,N]$ 中满足数位限制的数 | 数位 DP | 前导零、上界限制、记忆化维度 |
| 依赖无环、路径计数/最优值 | DAG DP | 拓扑顺序与不可达初值 |
| 随机过程的期望步数/收益 | 概率与期望 DP | 线性方程、自环概率与终止条件 |
| 左/右首个更大更小、贡献范围 | 单调栈 | 严格与非严格比较符号 |
| 固长窗口最值、DP 滑窗优化 | 单调队列 | 队首过期；队尾维护单调性 |
| 动态连通、合并集合 | 并查集 | 不能直接处理删除；路径压缩+按秩合并 |
| 单点改、前缀和、区间和 | 树状数组 | 下标通常从 1 开始 |
| 区间加与区间求和 | [线段树（区间加）](#57) | 懒标记合并、闭区间端点与建树范围 |
| 区间赋值、区间加与区间求和 | [线段树（区间赋值与加法）](#513) | 赋值覆盖旧加法；之后的新加法累加到赋值值上 |
| 单点修改、自定义区间聚合 | [单点修改线段树与自定义合并](#point-segment-tree-custom-merge) | 合并需满足结合律并提供双侧单位元；非交换合并须保持左右顺序 |
| 静态区间最值、幂等运算 | ST 表 | 无修改；查询 $O(1)$ |

## 10.3 图与树 {#q-index-graph}

| 题意关键词 | 候选模板 | 使用前核对 |
|---|---|---|
| 依赖、先修、判有向环 | 拓扑排序 | 只适用于 DAG；输出数不足即有环 |
| 无权/等权最短路 | BFS | 多源时所有源同时入队 |
| 非负边最短路 | Dijkstra | 负边不可用；跳过堆中旧状态 |
| 有负边、判可达负环 | [Bellman–Ford](#63-bellmanford) | 第 `n` 轮松弛；负环定义是否限源可达 |
| 全源最短路、点数较小 | Floyd | $O(n^3)$；中转点必须最外层 |
| 无向图最小生成森林 | Kruskal | 本章模板用排序边集加并查集；不连通时得到森林 |
| 左右两类配对、任务分配 | 二分图最大匹配 | 图是否确实二分；增广路访问标记 |
| 每条边恰走一次 | 欧拉路径/回路 | 度数条件、连通性、有向/无向版本 |
| 布尔选择与“至少一个”的二元约束 | 2-SAT | 每条约束转为蕴含边；变量与否定编号 |
| 有向图互相可达、缩点 | 强连通分量 | Tarjan 栈内标记与低链更新来源 |
| 删点/删边使无向图断开 | 割点与桥 | 返祖边、重边、DFS 根的特殊规则 |
| 子树区间、树上离线统计 | DFS 序/子树展平 | 进入/退出时间及区间端点 |
| 子树颜色/频次统计、保留重儿子信息 | [DSU on Tree](#514-dsu-on-tree) | 子树遍历次序、清空轻儿子贡献与复杂度 |
| 祖先、两点树上距离 | 倍增 LCA | 深度对齐；预处理根与倍增层数 |
| 树上最远点、最长路径 | 树的直径 | 负边权时两次最远点法需重新确认 |
| 容量、可同时输送的最大量 | Dinic 最大流 | 反向边下标、残量网络、`long long` 容量 |
| 单位费用、在最大流下最小成本 | 最小费用最大流 | 负费用、势能/最短路与溢出 |
| 任意子树/路径修改查询 | 树链剖分 | DFS 序方向与线段树区间一致 |

## 10.5 五秒模型核对 {#q-index-final-check}

```text
1. 数据范围允许这个复杂度吗？多测看总规模。
2. 模板前提满足吗：有序、单调、非负、无环、二分、连通？
3. 题目要的是值、方案、数量，还是字典序最小方案？
4. 下标、区间、无解状态、重边、自环、负权、取模是否对齐？
5. 复制模板后，哪三个位置必须按本题修改？
```

## 10.6 常用英文术语对照 {#q-index-english-terms}

用于阅读英文题面；单调性直接核对不等号，避免把允许相等误读为严格变化。

| 中文 | 英文常见表述 | 含义 / 易混点 |
|---|---|---|
| 非递减（单调不减） | non-decreasing / nondecreasing | $a_i\le a_{i+1}$，允许相等 |
| 严格递增 | strictly increasing | $a_i<a_{i+1}$ |
| 非递增（单调不增） | non-increasing / nonincreasing | $a_i\ge a_{i+1}$，允许相等 |
| 严格递减 | strictly decreasing | $a_i>a_{i+1}$；单独的 increasing / decreasing 需看题面定义 |
| 升序 / 降序 | ascending / descending order | 是否允许相等以题面为准 |
| 互不相同 | distinct / pairwise distinct | 任意两个元素不相等 |
| 集合 | set | 不计重复元素，元素无顺序 |
| 多重集合 | multiset | 允许重复，计入各元素出现次数；元素无顺序 |
| 子集 / 真子集 | subset / proper subset | 子集可等于原集合；真子集不可 |
| 并集 / 交集 / 差集 | union / intersection / set difference | 差集 $A\setminus B$ 有方向 |
| 不相交 | disjoint | 交集为空；pairwise disjoint 表示两两不相交 |
| 序列 / 数组 | sequence / array | 有顺序，可含重复元素 |
| 子序列 | subsequence | 删除若干元素得到，保持相对顺序，不要求连续 |
| 子数组 / 子串 | subarray / substring | 连续的一段；字符串题中的 subsequence 仍可不连续 |
| 前缀 / 后缀 | prefix / suffix | 从开头 / 到结尾的一段；proper prefix / suffix 不含整个序列 |
| 排列 | permutation | 常指 $1$ 到 $n$ 各出现一次；也可指给定元素的重排，需看定义 |
| 字典序 | lexicographical order / lexicographic order | 首个不同元素决定大小；一方为另一方前缀时较短者更小 |
| 连续的 / 相邻的 | consecutive / adjacent | consecutive integers 指连续整数；adjacent 常指相邻位置或图中邻接 |
| 至多 / 至少 / 恰好 | at most / at least / exactly | 分别对应 $\le$ / $\ge$ / $=$ |
| 任意 / 存在 | for every / there exists | 分别为全称 / 存在量词；any 需结合上下文判断 |
| 非负 / 正 / 非正 / 负 | non-negative / positive / non-positive / negative | 分别对应 $\ge0$ / $>0$ / $\le0$ / $<0$ |
| 向下取整 / 向上取整 | floor / ceiling (ceil) | $\lfloor x\rfloor$ / $\lceil x\rceil$；负数时向下取整不等于向零截断 |
| 因数 / 倍数 | divisor (factor) / multiple | $d$ divides $n$ 表示 $d\mid n$ |
| 互质 | coprime / relatively prime | 最大公约数为 $1$；pairwise coprime 表示两两互质 |
| 余数 / 取模 | remainder / modulo | 负数的余数约定需核对题面与语言行为 |
| 无向图 / 有向图 | undirected graph / directed graph | 边是否有方向 |
| 顶点 / 边 / 度数 | vertex (node) / edge / degree | 有向图另分 in-degree（入度）与 out-degree（出度） |
| 重边 / 自环 | parallel edges (multiple edges) / self-loop | 同端点的多条边 / 端点为同一顶点的边 |
| 简单图 | simple graph | 通常无重边、无自环；以题面定义为准 |
| 连通分量 | connected component | 无向图的极大连通部分；有向图需区分强连通与弱连通 |
| 路径 / 环 | path / cycle | 顶点或边能否重复须核对定义；simple path 通常要求顶点不重复 |
| 子树 / 祖先 / 后代 | subtree / ancestor / descendant | 是否包含节点自身需看定义；strict ancestor 排除自身 |
| 生成树 / 最小生成树 | spanning tree / minimum spanning tree (MST) | 覆盖所有顶点的树 / 总边权最小的生成树 |
| 可行解 / 最优解 | feasible solution / optimal solution | 满足约束 / 在可行解中使目标最优 |
| 任意一个解 | any solution / any valid answer | 输出一个合法解即可，通常无须最优或字典序最小 |
| 对某模数取模输出 | modulo $m$ | 输出答案模 $m$；通常规范到 $[0,m-1]$（$m>0$） |
