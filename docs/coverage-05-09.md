## 具体修订

- 图论、数学、字符串与计算几何共 46 节沿用数据结构章的八部分讲解结构，补充真实变量映射、函数契约、带断言的调用示例、改造方法及边界自检；保留既有算法、章节编号与稳定锚点。核对有向/无向建图、对象复用、残量增广、模数与整数范围、字节下标、匹配重叠以及浮点退化和凸包输入条件。
- 数据结构章 5.1–5.15 参考用户提供的 DSU on Tree 讲解稿，统一为用途、变量、函数、调用、改造、自检、易错点与一句话原理八部分；保留既有模板接口和标题锚点，补充可手算调用示例。核对 DFS 序与统计维度的区别、懒标记和重复构建前提、树链剖分方向，以及自定义合并的顺序与单位元要求。
- 保留了完整章节的知识说明和代码，合并重复的“速查介绍 / 使用方法 / 标准模板”层级为行内标签，并移除分页指令与重复代码标签。
- 为 Fenwick 增加按前缀和二进制提升的 `lowerBound`；明确频次须非负，未找到时返回 `n+1`。另增 5.13 线段树，涵盖区间加、区间赋值与区间和，并明确赋值标志与加法标志的合成次序。
- Bellman–Ford 中间距离改用 `__int128`，避免 `long long` 松弛溢出；说明原地松弛可能一轮推进多条边，并在发现可达负环时返回标志且不暴露部分距离。有限距离必须能放进 `long long` 且小于 `INF`。
- Dinic 和最小费用流的反向边下标处理自环；最大流与费用流均要求源点、汇点不同。最小费用流限制说明包括 SPFA 复杂度、费用范围及残量网络负环前提。
- 2-SAT 接入本章实际的 `TarjanSCC` API；区间 Fenwick 接入本章实际 `Fenwick::prefixSum`；圆交点模板复用第 9.1 节 `Point`、`dot`、`length`、`EPS` 定义。整数方向代码在做差前提升坐标类型。
- 数学、字符串、几何各节明确“适用范围 / 能做什么 / 输入输出”，补充函数级参数、返回值、修改效果、索引和失败语义注释；几何明确 EPS、公共类型及 `__int128` 的中间值限制。其余模板保留编号、区间开闭和退化情形说明。
